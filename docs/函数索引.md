# 函数索引

**简体中文** · [English](FUNCTIONS.md)

`Lib_Tool R1.lua` 共定义 **63 个函数**：62 个顶层 `local function`，外加 1 个嵌套在 `CFG_FILES` 初始化块中的 `push`。**不向全局环境写入任何变量**（生成的输出脚本中的 `so` / `py` 除外），因此与其它 GG 脚本共存时不会互相污染。

约定：

- 参数表中的 `sel` 指勾选项数组（`gg.getSelectedListItems()` 去重后的结果），下标 1..N 与 `chosen` / `values` / `freeze` 的键一一对应。
- 返回 `nil` 表示「用户取消」或「条件不满足」，调用方需区分这两类（前者静默中止，后者通常已弹窗说明）。
- 「记录」指 `{module, seg_start, seg_end, offset, flags, value, freeze, value_addr}`。

| 字符串 | 含义 |

| `bad path` | 路径不满足 `path_ok` |
| `bad name` | 取不到文件名 |
| `target path blocked by stale FUSE cache` | 目标路径的 dentry 已坏死，所有回退均失败 |
| 其它 | 来自 `io.open` / `f:write` 的原始错误 |

## 调用关系

```
入口（顶层代码）
├─ math.randomseed (pcall)
├─ ensure_cfg                      先定语言，再判 session
│   └─ read_cfg → cfg_blob_from_file ×3 / cfg_blob_from_gg
│                └─ deserialize → LANG = cfg.lang
│   └─ write_cfg → serialize → try_write ×3 / gg.saveVariable
├─ gg.getRangesList() == 0        空则 alert(t("no_session")) + return
├─ load_ranges
├─ gg.showUiButton
└─ while RUNNING
    └─ main_menu
        ├─ 1 → flow_static_address
        │   ├─ step_pick_list      → load_selected, all_static
        │   ├─ step_filter_modules → module_of, basename
        │   ├─ step_select_items   → describe → t
        │   ├─ step_pick_freeze    → collect_chosen, describe
        │   ├─ step_edit_values    → collect_chosen, parse_num
        │   ├─ make_record         → range_of, static_module, hex_addr
        │   ├─ verify_rows         → range_of
        │   ├─ step_pick_formats   → read_cfg, normalize_formats, fmt_label
        │   ├─ step_output_opts    → read_cfg
        │   ├─ resolve_out_path    → norm_path, path_ok
        │   ├─ sort_rows
        │   ├─ format_paths → split_name
        │   ├─ render → fmt_lua / fmt_json / fmt_csv
        │   ├─ write_output → try_write → raw_write / safe_remove / probe_readable / drop_tmp
        │   └─ read_cfg + write_cfg + history_push
        ├─ 2 → toggle_lang → read_cfg, write_cfg
        └─ 3 → RUNNING = false（退出脚本）
```

## 返回值语义速查

| 返回 | 调用方应做 |
| --- | --- |
| `nil`（来自 `gg.choice` / `multiChoice` / `prompt`） | 视为用户取消，静默 `return` |
| `nil`（来自业务函数，如 `resolve_out_path`） | 通常已弹窗说明原因，直接 `return` |
| `false`（来自 `write_cfg`） | 已 toast 提示，流程可继续 |
| `false, err`（来自 `try_write`） | 交给 `write_output` 换下一个目录重试 |
| `ok, saved_path`（来自 `try_write`） | 必须使用 `saved_path`，不要用入参 |
